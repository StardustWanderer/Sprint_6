# Юнит-тестирование с использованием Junit и Mockito (Спринт 6)

Проект содержит модульные автотесты (Unit-тесты) для классов `Cat`, `Feline` и `Lion`. В рамках проекта реализовано изолированное тестирование с использованием моков, параметризованные тесты, а также настроена генерация отчётов покрытия кода с помощью JaCoCo.

🛠 Технологический стек
* **Язык программирования:** Java (v11)
* **Тестовый фреймворк:** JUnit 4 (v4.13.2)
* **Фреймворк для мокирования:** Mockito (v5.23.0)
* **Инструмент анализа покрытия:** JaCoCo Maven Plugin (v0.8.15)
* **Сборщик проектов:** Maven

🏗 Архитектура проекта
Тестирование построено с соблюдением принципов слабого связывания и изоляции компонентов:
* **Dependency Injection (Инъекция зависимостей):** Класс `Lion` больше не создаёт объект `Feline` внутри себя, а получает его через конструктор `Lion(String sex, Feline feline)`.
* **Изоляция тестов:** Для исключения влияния реального класса `Feline` на тесты классов `Cat` и `Lion` используются моки (`@Mock` / `Mockito.mock()`).
* **Разделение тестов:** Параметризованные тесты вынесены в отдельный класс.

🧪 Тестовые классы:
* `CatTests` — проверки методов класса `Cat` (возвращаемый звук и вызов метода питания через изолированный `Feline`).
* `FelineTests` — проверки методов семейства `Feline` (хищный рацион, семейство кошачьих, а также дефолтного и перегруженного методов `getKittens()`).
* `LionTests` — основные юнит-тесты класса `Lion` с использованием моков для `Feline` (получение еды, котят, а также проверка выброса `Exception` при некорректном поле).
* `LionParameterizedTest` — параметризованный тест для проверки логики наличия гривы (`doesHaveMane()`) для разных полов («Самец», «Самка»).
