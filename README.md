# Юнит-тестирование на Java: JUnit 4, Mockito и JaCoCo

## О проекте

Учебный проект, выполненный в рамках финального проекта 6-го спринта курса «Инженер по тестированию: автоматизация на Java» от Яндекс Практикума.

Основная задача — разработать модульные тесты для классов `Cat`, `Feline` и `Lion`, используя JUnit 4 и Mockito. Также необходимо добиться 100% покрытия целевых классов с помощью JaCoCo.

В дополнительной части задания реализован класс `AlexLion` — наследник `Lion`, представляющий льва Алекса из мультфильма «Мадагаскар». Для него также написаны отдельные тесты.

## Технологический стек

- **Язык программирования:** Java 11
- **Сборщик проекта:** Maven
- **Фреймворк тестирования:** JUnit 4.13.2
- **Фреймворк для создания моков и шпионов:** Mockito 5.23.0
- **Инструмент анализа покрытия:** JaCoCo Maven Plugin 0.8.15

### Конфигурация Maven

В проекте используются следующие плагины:

- `maven-compiler-plugin` 3.8.1 — компиляция исходного кода с использованием Java 11.
- `maven-surefire-plugin` 3.2.5 — запуск тестов.
- `jacoco-maven-plugin` 0.8.15 — сбор статистики покрытия и генерация HTML-отчёта.

JUnit и Mockito подключены с областью действия `test`.

## Структура проекта

### Основные классы

- `Animal` — базовый класс, содержащий методы получения рациона и информации о семействе животных.
- `Predator` — интерфейс, определяющий метод получения пищи хищника `eatMeat()`.
- `Feline` — класс семейства кошачьих, реализующий интерфейс `Predator`. Содержит методы получения рациона, определения семейства и подсчёта котят.
- `Cat` — класс кошки с методами получения звука и рациона. Использует композицию и переданную через конструктор зависимость для получения пищи.
- `Lion` — класс льва, определяющий наличие гривы в зависимости от пола животного. Получает зависимость `Feline` через конструктор.
- `AlexLion` — дополнительный класс льва Алекса, наследующий `Lion`. Содержит информацию о друзьях и месте проживания, а также переопределённый метод подсчёта котят.

### Тестовые классы

- `CatTests` — проверка возвращаемого звука и получения рациона через зависимость `Feline`.
- `FelineTests` — проверка получения рациона хищника, определения семейства и работы перегруженных методов `getKittens()`.
- `LionTests` — проверка получения рациона и количества котят, а также обработки некорректного значения пола при создании объекта.
- `LionParameterizedTest` — параметризованная проверка наличия гривы у льва в зависимости от пола.
- `AlexLionTests` — проверка конструктора, списка друзей, места проживания и переопределённого метода `getKittens()`.

## Подходы и техники тестирования

В проекте применены следующие техники модульного тестирования:

- **Изоляция зависимостей** — тестирование классов независимо от реальной реализации зависимых объектов.
- **Mocking** — создание заглушек с помощью аннотации `@Mock` и метода `Mockito.mock()`.
- **Spying** — использование `Mockito.spy()` для частичной подмены поведения реального объекта и проверки делегирования между методами.
- **Stubbing** — настройка поведения моков и шпионов с помощью `when().thenReturn()` и `doReturn().when()`.
- **Verification** — проверка взаимодействия тестируемого объекта с зависимостями с помощью `Mockito.verify()`.
- **Parameterized Testing** — использование параметризованных тестов JUnit 4 для проверки нескольких значений входных данных.
- **Exception Testing** — проверка выбрасывания исключения при передаче некорректного значения пола животного.
- **Dependency Injection** — передача зависимостей через конструкторы.

## Дополнительное задание: AlexLion

Реализован класс `AlexLion`, наследующий `Lion`.

Дополнительная функциональность:

- `getFriends()` — возвращает список друзей Алекса: Марти, Глория и Мелман.
- `getPlaceOfLiving()` — возвращает место проживания: Нью-Йоркский зоопарк.
- `getKittens()` — переопределяет родительский метод и возвращает `0`, поскольку у Алекса нет львят.
- Конструктор вызывает `super()` с фиксированным значением пола «Самец».

Дополнительный класс покрыт отдельными тестами.

## Запуск тестов

Для запуска всех тестов и генерации отчёта JaCoCo выполни команду:

```bash
mvn clean test
```

HTML-отчёт JaCoCo формируется по следующему пути:

```text
target/site/jacoco/index.html
```

Для просмотра отчёта открой файл `index.html` в браузере.
